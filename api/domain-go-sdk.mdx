Install the Go SDK from the public Pxxl repository:

```bash
go get github.com/pxxlspace/pxxlspace/sdks/go/pxxl
```

```go
client, err := pxxl.NewClient(os.Getenv("PXXL_API_KEY"))
if err != nil {
  log.Fatal(err)
}
```

Use an API key with `scope=domain`, `scope=domains`, or `scope=all`. Read-only keys can list and check domains. Write keys can connect domains and modify DNS records.

## Connect a Domain

```go
connected, err := client.ConnectDomain(context.Background(), pxxl.ConnectDomainInput{
  Domain: "example.com",
  ProjectID: "proj_123",
})
if err != nil {
  log.Fatal(err)
}

fmt.Println(connected["domainId"])
```

## Connect to a Microservice

For monorepo or multi-service projects, pass the microservice ID as `MicroserviceID`, `ServiceID`, or `ServiceAlias`:

```go
connected, err := client.ConnectDomain(context.Background(), pxxl.ConnectDomainInput{
  Domain: "api.example.com",
  ProjectID: "proj_123",
  MicroserviceID: "api",
})
if err != nil {
  log.Fatal(err)
}

fmt.Println(connected["serviceAlias"])
```

Pxxl keeps the domain attached to the parent project and routes traffic to the selected microservice target.

## Check and Verify

```go
check, err := client.CheckDomain(context.Background(), "example.com", "")
verify, err := client.VerifyDomainRecord(context.Background(), pxxl.VerifyDomainRecordInput{
  Domain: "example.com",
  ProjectID: "proj_123",
})
activation, err := client.ActivateDomain(context.Background(), "dom_123", "")
status, err := client.GetDomainConnectionStatus(context.Background(), "dom_123", "")
```

`CheckDomain` inspects Pxxl ownership, proxy state, SSL state, and availability. `VerifyDomainRecord` checks that the project DNS records are pointed correctly.

Pxxl auto-detects pending external domains for up to 24 hours after connection, checking every 5 minutes until the expected `A` record resolves. Call `VerifyDomainRecord` when you want an immediate check after changing DNS.

Use `GetDomainConnectionStatus` for a dashboard-style readiness check. It uses `.cv` managed zone status for `.cv` domains and the generic activation check for other TLDs. `GetDomainZoneStatus` remains available for older code and now follows the same dynamic behavior.

## Resync the Proxy Route

Use `ResyncDomainProxy` after changing the connected project, microservice target, SSL settings, force-HTTPS setting, or DNS state. It refreshes the route and certificate state without rebuilding the project.

```go
resync, err := client.ResyncDomainProxy(context.Background(), "example.com", "")
if err != nil {
  log.Fatal(err)
}

fmt.Println(resync)
```

For team-scoped domains, pass the team ID:

```go
resync, err := client.ResyncDomainProxy(context.Background(), "example.com", "team_123")
```

This method calls `POST /api/v3/cli/domains/:domain/resync`. It requires a domain-scoped API key with `read_write` permission.

## DNS Records

```go
records, err := client.ListDomainDNSRecords(context.Background(), "dom_123", "")

created, err := client.CreateDomainDNSRecord(context.Background(), "dom_123", pxxl.DomainDNSRecordInput{
  Type: "A",
  Name: "@",
  Value: "193.181.212.65",
  TTL: 60,
})

updated, err := client.UpdateDomainDNSRecords(context.Background(), "dom_123", pxxl.DomainDNSRecordInput{
  RecordID: "rec_123",
  Type: "A",
  Name: "@",
  Value: "193.181.212.66",
})

deleted, err := client.DeleteDomainDNSRecord(context.Background(), "dom_123", pxxl.DomainDNSRecordInput{
  RecordID: "rec_123",
})
```

For `.cv` and other Pxxl-managed domains, record changes are validated and logged for rollback in the dashboard.

## Disconnect a Domain

Use `DisconnectDomain` when a custom domain should stop routing to a project. This removes the project binding and proxy route, but it does not delete the domain from your registrar.

```go
deleted, err := client.DisconnectDomain(
  context.Background(),
  "example.com",
  "proj_123",
  "",
)
if err != nil {
  log.Fatal(err)
}

fmt.Println(deleted)
```

| Argument | Required | Description |
| --- | --- | --- |
| `domain` | Yes | Hostname to disconnect, such as `example.com` or `api.example.com`. |
| `projectID` | Recommended | Project currently connected to the domain. Include it to avoid removing the wrong binding. |
| `teamID` | No | Spaceship context for team-owned domains. |

## Certificates

```go
pemBytes, err := client.DownloadDomainCertificate(context.Background(), "dom_123", "")
if err != nil {
  log.Fatal(err)
}

if err := os.WriteFile("example.com.pem", pemBytes, 0600); err != nil {
  log.Fatal(err)
}
```

## Team Context

Most domain methods accept a `teamID` string or include `TeamID` in the input struct.

```go
domains, err := client.ListDomains(context.Background(), "team_123")
connected, err := client.ConnectDomain(context.Background(), pxxl.ConnectDomainInput{
  Domain: "team.example.com",
  ProjectID: "proj_123",
  TeamID: "team_123",
})
```

Usage limits are still enforced against the owning user account, even when a team context is selected.

## Limit Errors

When a plan cannot add another custom domain, the SDK returns an `*pxxl.APIError` with the raw JSON body available:

```go
var apiErr *pxxl.APIError
if errors.As(err, &apiErr) && apiErr.StatusCode == http.StatusForbidden {
  fmt.Println(apiErr.Message)
  fmt.Println(string(apiErr.Body))
}
```
