Install the official Python SDK:

```bash
pip install pxxl
```

```python
from pxxl import PxxlClient

pxxl = PxxlClient(api_key="pxxl_...")
```

Use an API key with `scope=domain`, `scope=domains`, or `scope=all`. Read-only keys can list and check domains. Write keys can connect domains and modify DNS records.

## Connect a Domain

```python
connected = pxxl.connect_domain("example.com", project_id="proj_123")
```

## Connect to a Microservice

For monorepo or multi-service projects, pass the microservice ID with `microservice_id`, `service_id`, or `service_alias`:

```python
connected = pxxl.connect_domain(
    "api.example.com",
    project_id="proj_123",
    microservice_id="api",
)
```

Pxxl keeps the domain attached to the parent project and routes traffic to the selected microservice target.

## Check and Verify

```python
check = pxxl.check_domain("example.com")
verify = pxxl.verify_domain_record("example.com", project_id="proj_123")
activation = pxxl.activate_domain("dom_123")
status = pxxl.get_domain_connection_status("dom_123")
```

`verify_domain_record` performs an immediate expected-record check for the project domain. Pxxl also auto-detects pending external domains for up to 24 hours after connection, checking every 5 minutes until the expected DNS record resolves.

Use `get_domain_connection_status` for a dashboard-style readiness check. It uses `.cv` managed zone status for `.cv` domains and the generic activation check for other TLDs. `get_domain_zone_status` remains available for older code and now follows the same dynamic behavior.

## Resync the Proxy Route

Use `resync_domain_proxy` after changing the connected project, microservice target, SSL settings, force-HTTPS setting, or DNS state. It refreshes the route and certificate state without rebuilding the project.

```python
resync = pxxl.resync_domain_proxy("example.com")
print(resync)
```

For team-scoped domains, pass `team_id`:

```python
resync = pxxl.resync_domain_proxy("example.com", team_id="team_123")
```

This method calls `POST /api/v3/cli/domains/:domain/resync`. It requires a domain-scoped API key with `read_write` permission.

## DNS Records

```python
records = pxxl.list_domain_dns_records("dom_123")

created = pxxl.create_domain_dns_record("dom_123", {
    "type": "A",
    "name": "@",
    "value": "193.181.212.65",
    "ttl": 60,
})

updated = pxxl.update_domain_dns_records("dom_123", {
    "recordId": "rec_123",
    "type": "A",
    "name": "@",
    "value": "193.181.212.66",
})

pxxl.delete_domain_dns_record("dom_123", {"recordId": "rec_123"})
```

Pxxl blocks invalid `CNAME` and `A` record conflicts before saving.

## Disconnect a Domain

Use `disconnect_domain` when a custom domain should stop routing to a project. This removes the project binding and proxy route, but it does not delete the domain from your registrar.

```python
deleted = pxxl.disconnect_domain(
    "example.com",
    project_id="proj_123",
)
print(deleted)
```

For team-owned domains:

```python
deleted = pxxl.disconnect_domain(
    "example.com",
    project_id="proj_123",
    team_id="team_123",
)
```

| Argument | Required | Description |
| --- | --- | --- |
| `domain` | Yes | Hostname to disconnect, such as `example.com` or `api.example.com`. |
| `project_id` | Recommended | Project currently connected to the domain. Include it to avoid removing the wrong binding. |
| `team_id` | No | Spaceship context for team-owned domains. |

## Certificates

```python
pem = pxxl.download_domain_certificate("dom_123")
open("example.com.pem", "wb").write(pem)
```

## Team Context

```python
team_pxxl = PxxlClient(api_key="pxxl_...", team_id="team_123")
domains = team_pxxl.list_domains()
```

Usage limits are still enforced against the owning user account, even when a team context is selected.
