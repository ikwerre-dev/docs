Install the official Rust SDK:

```bash
cargo add pxxl
```

```rust
use pxxl::{DomainDnsRecord, PxxlClient, VerifyDomainRecord};

let client = PxxlClient::new(std::env::var("PXXL_API_KEY")?)?;
```

Use an API key with `scope=domain`, `scope=domains`, or `scope=all`. Read-only keys can list and check domains. Write keys can connect domains and modify DNS records.

## Connect a Domain

```rust
let connected = client.connect_domain("example.com", "proj_123", None).await?;
```

## Connect to a Microservice

For monorepo or multi-service projects, use `connect_domain_to_service` with the microservice ID:

```rust
let connected = client
    .connect_domain_to_service("api.example.com", "proj_123", "api", None)
    .await?;
```

Pxxl keeps the domain attached to the parent project and routes traffic to the selected microservice target.

## Check and Verify

```rust
let check = client.check_domain("example.com", None).await?;
let verify = client.verify_domain_record(VerifyDomainRecord {
    domain: "example.com".into(),
    project_id: "proj_123".into(),
    team_id: None,
}).await?;
let activation = client.activate_domain("dom_123", None).await?;
let status = client.domain_connection_status("dom_123", None).await?;
```

`verify_domain_record` performs an immediate expected-record check for the project domain. Pxxl also auto-detects pending external domains for up to 24 hours after connection, checking every 5 minutes until the expected DNS record resolves.

Use `domain_connection_status` for a dashboard-style readiness check. It uses `.cv` managed zone status for `.cv` domains and the generic activation check for other TLDs. `domain_zone_status` remains available for older code and now follows the same dynamic behavior.

## Resync the Proxy Route

Use `resync_domain_proxy` after changing the connected project, microservice target, SSL settings, force-HTTPS setting, or DNS state. It refreshes the route and certificate state without rebuilding the project.

```rust
let resync = client.resync_domain_proxy("example.com", None).await?;
println!("{resync:?}");
```

For team-scoped domains, pass the team ID:

```rust
let resync = client
    .resync_domain_proxy("example.com", Some("team_123"))
    .await?;
```

This method calls `POST /api/v3/cli/domains/:domain/resync`. It requires a domain-scoped API key with `read_write` permission.

## DNS Records

```rust
let records = client.list_domain_dns_records("dom_123", None).await?;

let created = client.create_domain_dns_record("dom_123", DomainDnsRecord {
    r#type: Some("A".into()),
    name: Some("@".into()),
    value: Some("193.181.212.65".into()),
    ttl: Some(60),
    ..Default::default()
}, None).await?;

client.update_domain_dns_records("dom_123", DomainDnsRecord {
    record_id: Some("rec_123".into()),
    r#type: Some("A".into()),
    name: Some("@".into()),
    value: Some("193.181.212.66".into()),
    ..Default::default()
}, None).await?;

client.delete_domain_dns_record("dom_123", DomainDnsRecord {
    record_id: Some("rec_123".into()),
    ..Default::default()
}, None).await?;
```

Pxxl blocks invalid `CNAME` and `A` record conflicts before saving.

## Disconnect a Domain

Use `disconnect_domain` when a custom domain should stop routing to a project. This removes the project binding and proxy route, but it does not delete the domain from your registrar.

```rust
let deleted = client
    .disconnect_domain("example.com", Some("proj_123"), None)
    .await?;

println!("{deleted:?}");
```

For team-owned domains:

```rust
let deleted = client
    .disconnect_domain("example.com", Some("proj_123"), Some("team_123"))
    .await?;
```

| Argument | Required | Description |
| --- | --- | --- |
| `domain` | Yes | Hostname to disconnect, such as `example.com` or `api.example.com`. |
| `project_id` | Recommended | Project currently connected to the domain. Include it to avoid removing the wrong binding. |
| `team_id` | No | Spaceship context for team-owned domains. |

## Certificates

```rust
let pem = client.download_domain_certificate("dom_123", None).await?;
tokio::fs::write("example.com.pem", pem).await?;
```

## Team Context

```rust
let team_client = PxxlClient::new(std::env::var("PXXL_API_KEY")?)?.with_team_id("team_123");
let domains = team_client.list_domains(None).await?;
```

Usage limits are still enforced against the owning user account, even when a team context is selected.
